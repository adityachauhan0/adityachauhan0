# Aditya Chauhan

I build software that runs close to the machine: local AI agents, the systems under them, and tools other agents can call.

[Yuzu](https://adityachauhan0.github.io/yuzu) is what I'm shipping now. [X](https://x.com/dragonofllms) · [LinkedIn](https://www.linkedin.com/in/adityamc/)

## Selected work

**[Yuzu](https://github.com/adityachauhan0/yuzu)** · Swift
A local AI agent for macOS. The model runs on the machine through [uzu](https://github.com/trymirai/uzu). It connects to Slack, GitHub, Notion, and any MCP server, and learns a team's workflows from skill files. [Site](https://adityachauhan0.github.io/yuzu)

**[explore-index](https://github.com/adityachauhan0/explore-index)** · Python
An agent skill that stops coding agents from re-exploring a codebase they already mapped. Across 31 live runs it cut token use by 39.9% (p = 0.0005) with no loss in accuracy.

**[Laya](https://github.com/adityachauhan0/laya-computer-use)** · Python
A computer-use MCP for macOS. Accessibility builds the table of actions, an MLX model picks one, and the host types it after you approve.

**[deckdown](https://github.com/adityachauhan0/deckdown)** · JavaScript
A Markdown presentation engine for AI agents. Decks render locally to PDF, PNG, and PPTX, with no hosted service in the loop.

**[impact-compass](https://github.com/adityachauhan0/impact-compass)** · TypeScript
A CLI that pressure-tests a startup idea against public evidence: demand, competitors, and whether anyone is already paying. No model involved.
